# آرش سیتی RP آنلاین

نسخهٔ چندنفرهٔ بازی HTML «آرش سیتی RP». فایل `index.html` بازی را نمایش می‌دهد و `server.py` از طریق WebSocket موقعیت بازیکن‌ها را بین اعضای یک شهر مشترک ردوبدل می‌کند.

## فایل‌های پروژه

- `index.html` — خود بازی
- `server.py` — سرور وب و ارتباط زندهٔ بازیکن‌ها
- `requirements.txt` — وابستگی پایتون
- `Dockerfile` — راه‌اندازی در Runflare با Docker

## راه‌اندازی در Runflare با گوشی

1. این ZIP را دانلود و از حالت فشرده خارج کن.
2. در GitHub یک مخزن جداگانه با نامی مثل `arash-city-rp-online` بساز. فایل‌های این پروژه را مستقیماً در ریشهٔ مخزن آپلود کن؛ به‌خصوص `Dockerfile` و `server.py` باید در ریشه باشند. مخزن رباتت را بازنویسی نکن.
3. در پنل Runflare یک سرویس/آیتم تازه بساز و اتصال GitHub را انتخاب کن. همین مخزن و شاخهٔ `main` را انتخاب کن.
4. روش استقرار را **Dockerfile / Docker** بگذار تا فایل `Dockerfile` اجرا شود.
5. پورت برنامه را `8000` تنظیم کن. برنامه علاوه بر `8000`، متغیر محیطی `PORT` را هم می‌خواند و اگر Runflare آن را تنظیم کند از همان استفاده می‌کند.
6. استقرار را شروع کن و در Logs دنبال پیام شبیه `Running on http://0.0.0.0:8000` بگرد. اگر خطای build یا start دیدی، متن همان خطا را بررسی کن.
7. دامنه/لینک HTTPS ساخته‌شده توسط Runflare را باز کن. صفحه باید بازی آرش سیتی را نشان دهد.
8. برای آزمایش، لینک را روی دو گوشی یا در دو مرورگر/زبانه باز کن؛ برای هر نفر نام متفاوت بزن و «ورود به شهر» را فشار بده. شمار بازیکن‌های آنلاین نمایش داده می‌شود و شخصیت/ماشین بازیکن دیگر روی نقشه و داخل شهر دیده می‌شود.

## نکته‌های مهم

- این سرور یک اتاق مشترک دارد و برای این نسخه حداکثر ۴۰ اتصال هم‌زمان در نظر گرفته شده است؛ ظرفیت واقعی به منابع و محدودیت‌های سرویس بستگی دارد.
- چون وضعیت اتاق در حافظهٔ همان فرایند نگه‌داری می‌شود، برای این نسخه تعداد replica/instance را روی **۱** نگه دار. اگر چند replica راه‌اندازی شود، هرکدام حافظهٔ جدا دارد و بازیکن‌های بین replicaها را نمی‌بینند؛ برای مقیاس بزرگ‌تر باید پیام‌رسان/ذخیره‌سازی مشترک اضافه شود.
- نام بازیکن فعلاً فقط نام نمایشی است، نه حساب کاربری یا احراز هویت. موقعیت‌ها هنگام خروج/راه‌اندازی مجدد سرور ماندگار نیستند. ماشین‌های خریداری‌شده در این نسخه همچنان در مرورگر همان دستگاه ذخیره می‌شوند.
- این یک نمونهٔ چندنفرهٔ پایه است: سرور موقعیت‌ها را پخش می‌کند، اما هنوز ضدتقلب پیشرفته، چت جهانی، حساب کاربری، ذخیرهٔ ابری یا برخورد فیزیکی بین بازیکن‌ها ندارد.
- برای آنلاین بودن، بازی را از لینک Runflare باز کن؛ باز کردن `index.html` به‌عنوان فایل محلی (`file://`) به سرور وصل نمی‌شود.

## بررسی سلامت

بعد از استقرار می‌توانی در مرورگر مسیر `/healthz` را هم باز کنی. باید پاسخی شبیه `{"status":"ok","players":0}` دریافت کنی.
